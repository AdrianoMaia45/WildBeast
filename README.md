# WildBeast
## 📌 Sobre o Projeto

WildBeast é um projeto focado na construção de layouts modernos utilizando CSS Grid Layout.

O objetivo principal foi explorar técnicas avançadas de posicionamento e responsividade para criar uma interface dinâmica e organizada.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- CSS Grid Layout

---

## 🎯 Objetivos do Projeto

- Praticar CSS Grid
- Construir layouts modernos
- Desenvolver páginas responsivas
- Melhorar estrutura visual e organização

---

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- 📱 Smartphones
- 💻 Desktop
- 📲 Tablets
